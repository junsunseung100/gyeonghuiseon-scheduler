# UI 전면 개편 (DK풍) — 설계 (2026-10-08)

출처: DK 운영 대시보드 + 다담 접수실 참고. 시안(dash_mock2) 원장 승인. 목표: "허접해 보임" 해소 + 한눈에.

## 범위
### A. 앱 셸: 상단 탭 → 왼쪽 사이드바
- 그룹: 대시보드 / 일정(달력·오늘 할 일·주간) / 환자(환자·연락 안 됨) / 물품(물품·물품신청) / 기타(통계·설정).
- 아이콘 + 알림 뱃지(연락안됨·물품신청 건수). 모바일(≤760px)은 상단 축소 메뉴로 전환.
- **바로가기** 영역(사이드바 하단): 네이버 톡톡·블로그·홈페이지·카톡 채널 등 외부 링크(새 탭). 설정에서 추가/삭제, 서버 저장(settings.quick_links).

### B. 디자인 시스템
- 웹폰트 Noto Sans KR. 색 토큰(teal 포인트 + 차분한 pastel 카테고리색). 부드러운 카드/그림자/여백.
- index.html에 토큰·공통 컴포넌트 CSS. 전 탭에 카드 시스템 적용(물품·환자·설정 등 기존 화면도 자연히 개선).

### C. 대시보드 재디자인 (DK풍, 한눈에)
- 상단: "오늘" + 날짜 + 한마디.
- 통계 타일: 처방·문자/확인전화/문진/마무리/놓친 + **오늘 완료율 도넛**(완료/전체).
- "오늘 확인할 것" 체크리스트: 놓친·연락안됨·완주임박·물품경고·메모 → 확인하기/정상 뱃지(클릭 시 해당 화면).
- 오늘 할 일(순서대로, 체크로 완료) + 우리 메모.
- **미니 달력**: 날짜 칸 건수 뱃지, 클릭 → 그날 팝업(openDayModal). 다담식.

## 영향 파일
- index.html: 디자인 시스템 CSS + 셸 구조.
- main.ts: render()의 셸(사이드바), renderDashboard 재작성, 바로가기 렌더·핸들러, 설정에 바로가기/링크 UI.
- supabase.ts/types.ts: settings.quick_links(배열) 로드·저장.
- DB: settings에 quick_links jsonb 컬럼(마이그레이션).

## 비범위(다음)
- DK 매출·목표 도넛(매출 데이터 없음) → 완료율로 대체.
- 톡톡/카톡 양방향 상담 통합, 솔라피, 예약관리, 문구 틀 → 각각 별도 라운드.

## 수용 기준
- 사이드바로 바뀌고(모바일 축소), 전체가 DK풍으로 깔끔.
- 대시보드가 시안(dash_mock2)과 같은 구성으로 실제 데이터 표시.
- 바로가기 링크 추가/클릭 동작, 서버 저장.

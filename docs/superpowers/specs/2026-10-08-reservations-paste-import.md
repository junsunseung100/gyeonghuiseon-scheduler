# 예약 가져오기(네이버 복붙) — 설계 (2026-10-08)

출처 요구: "네이버 예약이 내 달력에 보이게 / 예약 엑셀을 넣으면 보이게." 원장(선희) 확정.

## 배경
- 네이버 예약(스마트플레이스)은 일반 한의원에 공개 API가 없음 → 실시간 자동 연동 불가.
  로그인 스크래핑은 약관 위반·자격증명 위탁·화면 변경에 취약 → **만들지 않음**.
- 엑셀 다운로드는 비밀번호·절차가 번거로워 원장이 포기 → **엑셀 업로드도 범위에서 제외**.
- 남는 현실적 방법: 네이버 예약자관리 표를 **복사(Ctrl+C) → 앱에 붙여넣기(Ctrl+V)** 로 가져오기.
- 문진일정 달력은 **한약 전화·문자 환자 전용**으로 그대로 둔다. 예약(주로 침)은 **별도 "예약" 탭**에서만 본다. (DK 예약관리 참고)

## 목표
네이버 예약 표를 복붙하면, **날짜별로 "오늘 누가 오나"** 가 한눈에 보이고,
한약 환자는 **색으로 눈에 띄게**, 침·미정은 검정으로 구분된다.

## 범위
### A. 예약 탭 (사이드바 "일정" 그룹에 추가)
- 문진일정 달력/오늘 할 일/주간 요약 아래에 **"예약"** 추가.
- 기존 문진일정 달력은 변경하지 않음(한약 워크플로 유지).

### B. 가져오기 — 붙여넣기 파서
- 예약 탭 상단에 **"예약 붙여넣기"** 텍스트 영역 + **[불러오기]** 버튼.
- 네이버 예약자관리 표를 드래그 복사해 붙이면, 붙은 텍스트에서 예약을 뽑아 저장.
- 붙는 형식(관찰됨): 각 예약이 아래 순서의 줄/탭 혼합으로 들어온다.
  ```
  상태(확정|신청|취소)
  이름
  전화번호 ⇥ 예약번호 ⇥
  이용일시 날짜 (예: 26.10.10.토)
  이용일시 시간 (예: 12:00)
  상품 (예: 통증 클리닉(약침/침))
  옵션 / 총금액 / 신청일시 / 확정일시 / 취소일시 …  ← 버림
  ```
- 파서 규칙:
  - 상단 잡음(오늘이용/확정대기/오늘취소/N건/내려받기/상세 내려받기/인쇄/헤더 라벨)은 무시.
  - **상태 토큰(확정|신청|취소)** 을 만나면 새 예약 시작.
  - 이름 = 상태 다음의 숫자/날짜/전화 아닌 첫 줄.
  - 전화번호 = `01\d-?\d{3,4}-?\d{4}`.
  - 예약번호 = 10자리 숫자(`\b\d{10}\b`) — **중복 방지 키**.
  - 이용일시 = **첫** `\d{2}\.\d{1,2}\.\d{1,2}\.[월화수목금토일]` + 인접 `\d{1,2}:\d{2}` (뒤의 신청/확정일시는 무시).
    - 날짜 `YY.M.D` → `20YY-MM-DD`(로컬), 시간 `H:MM`.
  - 상품 = 이용일시 시간 바로 다음 줄.
  - 취소 상태도 `status='취소'`로 저장하되, 날짜별 목록에서는 기본 제외(숨김).
- **중복/갱신**: 예약번호가 이미 있으면 새로 만들지 않고 해당 행을 갱신(upsert). 매일 붙여도 안전.
- 불러오기 후 "N건 추가 / M건 갱신 / K건 무시" 요약 표시.

### C. 분류·색
- 자동: 상품 문자열에 **설정 키워드(기본 한약·첩약·탕약)** 포함 → `type='한약'`. 아니면 `type='침'`.
  - 주의: **"약침"은 한약 아님**(침 계열). 키워드를 "한약/첩약/탕약"로 두면 "약침/침"에는 걸리지 않음. "약" 단독 키워드 금지.
- 수동: 목록에서 한 행을 클릭해 **한약↔침 토글**(수동 지정은 자동 추측보다 우선, 재가져오기에도 유지).
- 색: 한약 = 눈에 띄는 강조색(설정에서 변경, 기본 골드/주황 계열), 침·미정 = 검정.
- 기본 전제(원장 확인): **네이버 예약은 보통 침 환자.** 한약용 네이버 상품명은 추후 원장과 재설계(아래 "나중").

### D. 화면 — 날짜별 목록(A안)
- 상단: **날짜 선택**(◀ / 오늘 / ▶), 기본값 = 오늘. (선택 시 그날로)
- 아래: 그날 예약 **표**, 시간 오름차순. 한 줄:
  `시간 · 상태(확정/신청) · 이름 · 상품(메뉴) · 연락처 · [📩 문자]`
  - 한약행은 강조색, 침·미정행은 검정.
  - [📩 문자] = 전화번호로 문자 앱 열기(기존 SMS 동작 재사용).
  - 행 클릭 → 한약↔침 토글.
- 예약 없는 날: "이 날 예약 없음".

### E. 저장 (Supabase)
- 새 표 `reservations`:
  | 칼럼 | 타입 | 설명 |
  |---|---|---|
  | id | uuid pk | |
  | resv_no | text unique | 네이버 예약번호(중복 방지) |
  | name | text | 예약자 |
  | phone | text | 전화번호 |
  | menu | text | 상품명 |
  | resv_date | date | 이용일(로컬 YYYY-MM-DD) |
  | resv_time | text | 이용시간 HH:MM |
  | status | text | 확정/신청/취소 |
  | type | text | 한약/침 (자동+수동) |
  | type_manual | bool | 수동 지정 여부(재가져오기 때 자동 덮어쓰기 방지) |
  | note | text | 메모(선택) |
  | created_at | timestamptz default now() | |
- RLS: 기존 표들과 동일(authenticated = 전체 접근). 앱은 PIN 서버 게이트 뒤에 있음.
- supabase.ts: loadAll에 reservations 추가(없으면 `?? []`), upsertReservations / updateReservation / deleteReservation.

### F. 설정
- "예약 분류 키워드" 입력(기본 한약,첩약,탕약) — settings에 저장.
- 한약 강조색은 기존 색 설정 체계에 추가(또는 전용 한 칸).

## 비범위 (나중, 각각 별도 라운드)
- 네이버 자동 긁기(로그인 스크래핑) — 안 함.
- 엑셀/CSV 업로드 — 보류(비번·절차 번거로움).
- 예약 환자 ↔ 한약 처방 워크플로 연결(내원 시 한약 전환 등).
- 솔라피 자동발송, 카톡/톡톡 상담 통합.

## 나중에 원장과 함께
- **네이버 예약 상품명 재설계**: 한약 예약을 네이버에서 구분 가능하게(상품명에 "한약" 포함 등) 정리 → 그 뒤 자동 색 분류가 더 정확해짐.

## 수용 기준
- 사이드바 "예약" 탭이 생기고, 문진일정 달력은 그대로다.
- 네이버 예약자관리 표를 복사해 "예약 붙여넣기"에 넣고 [불러오기]를 누르면, 예약이 저장되고 날짜별 목록에 뜬다.
- 같은 표를 다시 붙여도 중복이 생기지 않는다(예약번호 기준 갱신).
- 상품이 "통증 클리닉(약침/침)"인 예약은 검정으로, "한약" 포함 상품은 강조색으로 뜬다. 행 클릭으로 한약↔침을 바꿀 수 있고 재가져오기 후에도 유지된다.
- 각 행에서 [📩 문자]로 그 환자에게 문자 앱을 열 수 있다.

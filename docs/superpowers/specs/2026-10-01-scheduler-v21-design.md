# 문진일정 달력 V2.1 — 수정 설계 (2026-10-01)

출처: 4회차 발표 조원 피드백("환자가 많아지면 달력이 복잡") + 간호사 요청 + 개선 인사이트. 원장 일월 승인.

## 범위 (이번 라운드)

### A. 달력 복잡함 해소 — 압축 + 필터
- **압축 chip**: 달력 칸의 항목을 작은 한 줄 `● 이름 번호`로. `●`는 종류 색 점. 여백 축소로 더 많이 담고, 넘치면 기존처럼 칸 내부 스크롤.
- **필터 바**(달력 위): 종류 체크(확인전화·문진예정·처방문자·마무리문자1/2·재연락·메모·연락대기) + "완료 숨기기" 토글. 해제한 종류는 달력에서 숨김.
  - 저장: 기기별 편의 설정이므로 `localStorage`(try/catch). 공유 상태 아님.
- 상세·버튼은 기존 날짜 클릭 팝업(openDayModal) 그대로.

### B. 토·일·공휴일 전면 제외
- 토요일을 일요일·공휴일과 동일 취급: 자동 일정이 토요일에 안 잡히고 이동, 토요일 칸은 메모만.
- 구현: `settings.weekly_closed`에 6(토) 추가 → `isClinicClosed(토)=true` → confirmCallDate/followupDate 등이 토요일 회피. openDayModal `blocked` 조건에 `dow===6` 추가(메모만). 기존 '토요일 문진 최대 3개'(max_saturday) 로직 제거.
- 목요일(4)은 현행 유지: 처방문자 가능(처방일에 직접 배치), 확인전화·문진은 회피.
- CLAUDE.md 도메인 규칙 갱신.

### C. 한 줄 메모칸 (아무 날)
- openDayModal: 쉬는 날뿐 아니라 **모든 날**에 '한 줄 메모' 입력칸 노출. 기존 insertMemo 재사용. 달력엔 '메모' 종류로 표시(필터 대상).

### D. 색 단순화 + 색 바꾸기
- 기본 COLOR 팔레트를 차분하게(검정·진회색 위주) 단순화.
- 설정 탭에 종류별 색 고르기(color input) 추가 → `settings.colors`(jsonb)에 저장, 모든 기기 공유.
- COLOR는 `settings.colors`를 읽어 기본값에 덮어씀(폴백=기본 팔레트).
- DB: `settings` 테이블에 `colors jsonb` 컬럼 추가(ALTER, Supabase에서 수행).

### 이번 제외
- 완주율·재방문 지표 대시보드 — 대시보드 전체 개편과 함께 다음 라운드.

## 영향 파일
- `src/holidays.ts` / `src/dates.ts` / `src/schedule.ts`: 토요일 차단(weekly_closed=6), max_saturday 제거. (순수 로직 → 테스트 함께 수정)
- `src/main.ts`: 압축 chip 렌더, 필터 바, openDayModal 메모칸·토요일 blocked, 설정 색 UI, COLOR를 settings.colors로.
- `src/supabase.ts` / `src/types.ts`: settings.colors 추가.
- `index.html`: 압축 chip·필터 바 스타일.
- `CLAUDE.md`: 토·일·공휴일 전면 제외, 색 설정 규칙 반영.

## 테스트
- dates/schedule: 토요일에 확인전화·문진·마무리문자가 안 잡히고 이동하는지. 처방일이 토요일이면(입력은 팝업에서 막지만) 로직상 처방문자 배치는 그대로. 기존 '토요일 문진 3개' 테스트 제거/수정.
- 색/필터/메모는 UI → 수동 확인(브라우저).

## 확인 방법(수용 기준)
- 달력: 항목이 압축되어 한 줄씩, 필터로 종류·완료 토글, 복잡도 감소.
- 토요일: 자동 일정 안 뜨고 메모만. 금요일 등으로 이동.
- 메모: 평일에도 한 줄 메모 추가되고 달력에 표시.
- 색: 설정에서 종류 색 바꾸면 달력/목록에 반영, 다른 기기도 동일.

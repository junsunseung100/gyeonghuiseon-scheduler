## 접수실 하루 흐름으로 묶은 아이디어

### 1. 예약·접수·대기 (오기 전 ~ 도착)
- 🟡 **오늘 예약 명단**: 붙여넣기(전자차트/엑셀)로 오늘 올 환자 목록 → 접수/추나/비급여 여부 체크. (DK 접수기록부)
- 🟡 **대기 현황판**: 접수 완료 → 진료 대기 → 상담/수납 단계 표시. 누가 오래 기다리는지.
- 🟢 **오늘 문진·연락 대상 자동 표시**: 이미 있음(대시보드). 예약 명단과 합치면 "오늘 접수실 할 일"이 한 화면.
- 🟡 **공휴일 전날 연락 대상 자동 표시**: (구디) 연휴 전 미리 챙길 환자.

### 2. 수납·결제 (진료 후) — 운영 숫자의 '입구'
- 🔵 **일일 수납 입력**: 환자별(또는 합계) 금액·결제수단(카드/현금/계좌)·급여/비급여 구분 입력. → 아래 운영 숫자가 전부 여기서 나옴.
- 🔵 **일일 결산**: 오늘 매출·환자 수·결제수단별 합계 자동. (DK 일일결산)
- 🔵 **월 현황·객단가·비급여 달성률**: 월 매출, 환자당 평균(객단가=매출/환자수), 비급여 비율/목표 달성. (DK 전체 대시보드)
- 🟡 **정액권/선결제 관리**: 남은 횟수·금액, 사용 차감. (구디/으라 정액권)

### 3. 연락 업무 (문자·알림·해피콜)
- 🟢 **문진·확인전화·마무리문자**: 이미 있음(반자동 문자).
- 🟡 **해피콜 관리**: 초진 환자 재진 유도 콜, 통화 기록·메모, 원장 전달 필요 표시. 재진율·주치의별 통계. (DK/구디/닥터두기)
- 🔵 **PC에서도 문자/카톡 자동 발송(솔라피 알림톡)**: 지금은 핸드폰 반자동 → 솔라피 연동 시 데스크 PC에서 바로. (여러 명 공통 권고)
- 🟢 **연락 안 됨/재연락 루프**: 이미 있음.

### 4. 한약 관련 (접수실이 돕는 부분)
- 🟡 **한약 대기방**: 처방전 출력 요청 → 출력 완료 체크로 사라짐. (DK)
- 🟡 **복용법 출력**: 성명·첩수 입력 → 복용 안내문(용량 자동 계산) 인쇄용. (DK)
- 🟢 **처방·문자·확인전화·문진 일정**: 이미 있음(핵심).
- 🟢 **약품/소모품 재고·물품신청**: 이미 있음(오늘 추가).

### 5. 기록·인수인계·응대
- 🟢 **우리 메모(공지/전달)**: 이미 있음(대시보드).
- 🟡 **환자 응대 기록**: 전화/요청/컴플레인 간단 로그, 다음 근무자 인수인계.
- 🟡 **비대면 진료 신청 접수**: 구글폼/링크로 받은 신청을 목록으로. (DK)

### 6. 운영·분석 (원장/데스크가 보는 숫자)
- 🔵 **월간 대시보드**: 신규/재진, 객단가, 비급여 달성률, 해피콜 현황, 미처리 오더. (DK 전체 대시보드)
- 🟡 **완주율·재방문**: 한약 완주(블록 채움) 비율, 재연락→재처방 전환. (이미 데이터 있음, 지표만 추가)
- 🔵 **추세**: 월별 신규 정착률 등.

## 완성도(디자인) — "허접해 보임" 해소
운영 숫자와 별개로, 보기·완성도를 같이 올릴 수 있음(새 데이터 불필요):
- 통일된 글꼴(웹폰트)·색 토큰·간격·카드/그림자 정리, 상단 요약 타일, 숫자 강조, 섹션 위계.
- 작은 차트(막대·추세선)로 숫자를 '보이게'(dataviz).
- 모바일/데스크 반응형 정리.
→ 운영 숫자 화면을 만들 때 이 디자인 언어로 함께 입히면 "DK처럼" 느낌이 남.

## 추천 단계 (한 번에 다 말고, 효과/난이도 순)

**1단계 — 운영 숫자의 입구 + 완성도** 🔵
- '일일 수납 입력'(환자 수·매출·결제수단·급여/비급여) → 일일결산 + 월 매출·객단가·비급여 달성률.
- 이 화면을 프로페셔널 디자인으로(= 체감상 "DK처럼"의 핵심). 가장 임팩트 큼.

**2단계 — 접수/대기·해피콜** 🟡
- 오늘 예약 명단(붙여넣기)·대기 현황 + 해피콜 기록·재진율.

**3단계 — 한약 대기방·복용법 출력** 🟡
- 접수실이 매일 쓰는 출력/대기 흐름.

**4단계 — 자동 발송(솔라피)·비대면 접수** 🔵/🟡
- 외부 서비스 연동(가입·심사 필요).

**디자인 폴리시는 각 단계에 같이 입힘.**

## 원장 선택 반영 (v2, 2026-10-08 밤)

수납·운영숫자는 **전자차트에서 하므로 제외**. 복용법은 **한약차트 새로 만들며 거기서** 하므로 제외. 집중할 3가지:

### ① 네이버 예약 + 예약관리 연동
- 현실: **네이버 예약은 외부 앱이 바로 읽는 공식 API가 사실상 없음.** 가능한 길:
  - (a) 🟢 **예약 명단 붙여넣기** — 네이버 예약 화면/엑셀을 복사→앱에 붙여넣기 → 오늘 예약·접수·대기 관리. 지금 바로 가능, 가장 안정적.
  - (b) 🟡 **브라우저 자동 수집(Playwright/Aside 류)** — 로그인해 예약을 자동으로 긁어옴. 되지만 **불안정**(네이버 화면 바뀌면 깨짐), 상시 실행 환경 필요.
  - (c) 🔵 **네이버 예약 파트너 API** — 사업자 승인 절차 필요, 조건 까다로움.
- 예약관리로 할 일: 오늘 예약→**접수→대기→완료** 단계, 문진/한약 일정과 **한 화면에 합치기**.
- 추천: **(a) 붙여넣기로 먼저** 예약관리를 만들고, (b) 자동수집은 뒤에 검토.

### ② 해피콜 + 한약 일정, '내 다이어리' 연동
- 🟡 **해피콜 관리**(앱 내): 대상 자동 산출·통화 기록·메모·원장 전달 필요·재진율 — 바로 제작 가능.
- "**내 다이어리 연동**"은 다이어리가 무엇인지에 따라 다름:
  - 구글 캘린더 → 🟡 구글 API로 양방향 연동 가능(이 세션에 구글 도구 있음).
  - 네이버 캘린더/종이 → 공식 연동 어려움 → 내보내기(.ics)/붙여넣기 수준.
- **확인 필요: '내 다이어리'가 무엇인가요?**(구글/네이버/종이/전자차트 등)

### ③ 솔라피 자동 발송
- 🔵 **가능**. 서버 함수(/api/send 같은)로 솔라피 API 호출 → 문자/알림톡 자동 발송. (/api/login 만든 것과 같은 방식)
- 원장님이 하셔야 할 전제(제가 안내):
  - 솔라피 가입 + **발신번호 등록**(인증) + **알림톡 템플릿 승인**(카톡 쓰려면, 심사 2~3일).
  - API Key 발급 → Vercel 환경변수.
- 무엇을 자동으로 보낼지 정하기: 처방문자? 확인전화 안내? 해피콜? 마무리문자?
- 안전장치: 자동이라도 **발송 로그/실패 표시**, 필요 시 확인 후 발송 옵션.

## 깨어나서 정해주실 것

2. 해피콜의 **'내 다이어리'가 무엇**인지.
3. 솔라피: 가입/발신번호/템플릿은 원장님 몫 — 진행 의향 있으면 제가 단계 안내. **무슨 문자를 자동으로** 보낼지.

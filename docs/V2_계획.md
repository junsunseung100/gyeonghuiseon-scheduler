출처: 간호사 실사용 피드백 + 간호사 회의 녹음. 일정: **V2 = 10월 2일(금) 점검 전까지**, **V2.1 = 10월 14일까지**(점검 피드백 반영).

## 받은 의견 → V2에서 고칠 내용 (실사용 + 회의 녹음)

| # | 받은 의견 | V2에서 고칠 내용 |
|---|---|---|
| 1 | 완료하면 달력에서 없어져 "그때 약 나갔구나"를 못 봄 | **완료해도 달력에 남기되 회색으로** 표시(기록 유지). 오늘 할 일에서는 빠짐 |
| 2 | 아이디·비번 로그인이 복잡함 | **간단한 비밀번호(4자리 PIN)** 로 들어가기 (접근 방식은 아래 ‘확정 필요’) |
| 3 | 오늘 할 일이 세로로만 쌓여 눈에 안 들어옴 | **지난 일·오늘·다가올 일을 가로 3열**로 한 화면에 |
| 4 | 달력 칸이 작다 | **일요일 칸을 좁히고 월~토 칸을 넓게** |
| 5 | 토요일은 오전진료만 | **토요일 문진예정 최대 3개**, 넘으면 금요일로 당기거나 월요일로 |
| 6 | 처방과 문자가 따로 떠서 중복 체크가 안 되고 하나만 처리됨 | **처방·문자를 한 항목으로 합침**("김나나 6-1 처방·문자", 확인전화처럼 하나) |
| 7 | 여러 명 문자를 한 번에 완료할 버튼이 없음 | 날짜 팝업에 **여러 명 선택 → 한 번에 완료** 버튼 |
| 8 | 일요일·개천절 같은 공휴일에 일정이 잡힘(연휴를 파악 못 함) | **법정공휴일을 미리 넣어둠**(개천절 등 양력 고정). 일요일·공휴일엔 자동 일정 안 잡히고 **회색+공휴일 이름 표시, 메모만** |

## 추가로 넣을 것 (과제 필수)

**오늘 한눈에 대시보드**
- 목적: 아침에 열면 오늘 할 일과 밀린 일을 한 화면에.
- 보는 사람: 원장·데스크 간호사. 행동: 오늘 전화·문진할 사람을 바로 고름.
- 화면 숫자·목록: 오늘 확인전화 N건·문진 N건·처방문자 N건, **연락 안 됨/대기 명단**, 이번 주 처방 인원, **완주 임박**(마지막 회차 다가온) 환자.

## 추천 (내가 제안 — 원장이 고르면 반영, 기본은 V2.1)

- **소개 경로 + 완주 이유 기록**: 신환 등록 때 "누구 소개", 완주 때 "왜 끝까지 왔는지" 한 줄. 통계에 소개 유입 집계(초진 61명 중 소개 34명 관리와 직결).
- **탕약 소진 3일 전 재내원 알림**, **내원 끊긴 환자 주간 관리**.
- 기대 효과일 뿐 아직 측정 전.

## Supabase 표 (기존 유지 + 변경)

- 기존 5표(patients, blocks, prescriptions, tasks, settings) 그대로.
- `tasks.status`의 `완료`는 이미 있음 → 달력에서 **숨기지 말고 회색으로** 보이게 바꿈(표 변경 없음, 화면만).
- 처방·문자 합침 → 처방일에 `처방`+`문자` 두 항목 대신 **`처방문자` 한 항목** 생성(생성 규칙만 변경).
- `settings`에 **토요일 문진 최대(기본 3)** 추가, `holidays`에 **법정공휴일 미리 채움**.

## 기능별 확인 방법

- 완료 회색: 완료 처리한 처방문자가 달력에 회색으로 남고, 오늘 할 일에선 사라지는지.
- 처방·문자 합침: 처방 입력 시 한 항목(처방문자)만 생기고, 한 번에 완료되는지.
- 일괄 완료: 문자 여러 명 체크 → 한 번에 완료되는지.
- 공휴일: 개천절(10-3)에 일정이 안 잡히고 회색+"개천절" 표시, 메모만 되는지. 일요일도 동일.
- 토요일 3개: 토요일에 문진 4번째가 잡히려 하면 금요일/월요일로 넘어가는지.
- 3열·달력 칸·PIN: 눈으로 확인.
- 대시보드: 오늘 건수·명단이 실제 데이터와 맞는지.
